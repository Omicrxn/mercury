The following guide will walk you through the process of installing Mercury.

## Installation

Install Mercury together with [Motion](https://motion.dev), which it runs on:

```package-install
npm install @omicrxn/mercury motion
```

Mercury requires Svelte 5. Motion is a peer dependency, so your app and Mercury share one copy of it — import Motion's utilities (`stagger`, `motionValue`, easing functions…) straight from `motion`.

## Animating Elements

Mercury brings Motion's animation props to Svelte attachments. Add `mercury()` to an element and give it the props you'd give a `<motion.div>`:

```svelte
<script lang="ts">
	import { mercury } from '@omicrxn/mercury';
</script>

<div
	{@attach mercury({
		initial: { opacity: 0, scale: 0.95 },
		animate: { opacity: 1, scale: 1 },
		whileHover: { scale: 1.05 },
		transition: { type: 'spring', duration: 0.3, bounce: 0 }
	})}
></div>
```
